Berkeley 广受好评的数据结构与算法课程。但是这门课不仅仅止于 DS，它使用 Java 讲授，同时也会涉及 Java 和 OOP 的教学。同时，这门课注重软件工程的思想，让你像一个软件工程师去思考。

这门课的作业质量极高，lab 让你自己实现课上的数据结构，project 更是让你在实战中运用所学的数据结构，这之中就包含十分出名的 gitlet。

但是我要检讨一下，我这门课上的效果不太好。我当时是在大一的暑假上这门课的，大概上了一个月。CSDIY 说预计学时 60 小时，我感觉是完全不够的。光 gitlet 估计都要 30 小时了。也因此我最后要开学的时候时间根本不够，最后的 lab 和 project 就水过去了。

因此我建议在大一的春夏学期来上这门课，给充足的时间。以及 project3 是一个两人的小组作业，最好能找一个同伴一起上这门课，也能起到互相督促的作用。

还有，课程只开放了 sp21 的 gradescope，但是我觉得不一定非要上 21 年的，毕竟这个也只是起到一个 autograder 的作用。你完全可以上你想上的学期，然后作业用 agent 给你评测，基本上问题不大。
